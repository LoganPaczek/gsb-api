# GSB API

API PHP realisee dans le cadre d'un projet scolaire.

## Contexte

Ce depot correspond a un projet d'atelier de professionnalisation, realise pendant mon BTS SIO (epreuve de validation).

Le but principal de ce projet est pedagogique : concevoir, structurer et tester une API REST en PHP.

## Important - Donnees et securite

Certaines informations peuvent apparaitre dans le depot (exemples : identifiants de test, structure SQL, jeu de donnees de demo).

Cela est volontaire dans ce contexte scolaire, pour faciliter l'evaluation technique du projet.

- Les comptes et mots de passe presents sont des valeurs de test
- La base de donnees fournie est une base de demonstration
- Les donnees utilisees sont uniquement fictives
- Aucune donnee personnelle reelle n'est exploitee

## Avertissement

Ce projet n'est pas destine a un usage en production.

Si vous reutilisez ce code :

- remplacez tous les secrets par des variables d'environnement securisees
- supprimez les identifiants publics
- appliquez les bonnes pratiques de securite (hash, droits, validation, etc.)
